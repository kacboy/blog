UMD2MKV | PSP UMD Ripping Software

If you have any UMD movies sitting around for the PSP and want to rip them for modern playback, the process has historically required navigating a frustrating chain of legacy tools. Standard utilities cannot natively parse Sony's proprietary .MPS video streams, forcing users to manually mount ISOs, demux H.264 streams, decode Sony's ATRAC3+ audio, and reassemble everything manually.

UMD2MKV is a utility designed to automate this entire workflow. By reading ISO9660 filesystems directly, it extracts raw video streams, reconstructs the audio, and remuxes everything into a clean, standard Matroska (.MKV) container with zero generational video loss.

Key Features & Conversion Modes

  • Direct ISO Parsing: Reads the ISO9660 filesystem directly, bypassing the need to manually mount or unpack disc images.
  • Lossless Video Stream-Copy: Extracts the original H.264 video stream without re-encoding, preserving native visual quality.
  • Flexible Audio Handling: Decodes Sony ATRAC3+ audio into AAC-LC at 256 kbps per track (recommended for broad compatibility and smaller file sizes) or opts for a lossless FLAC conversion.
  • Intelligent Language & Subtitle Mapping: Cross-references matching .CLP files under UMD_VIDEO/CLIPINF/ to map Sony's private-stream descriptors directly to standard ISO-639 language tags and track titles. Original PSP PNG subtitle streams are reassembled and packaged as selectable PGS .sup tracks.
  • Multiple Operational Modes:
    • Movie Mode (Default): Targets the largest .MPS file under UMD_VIDEO/STREAM/ as the primary feature.
    • TV Show Mode: Scans all streams sequentially and uses FFprobe to retain files longer than 3 minutes, filtering out menus and transitions while outputting sequentially named episodes (Title - E01.mkv, Title - E02.mkv).
    • All-Streams Mode: Bypasses duration filtering to extract every .MPS file on the disc for complete archival dumps.

System Requirements & Setup

  • FFmpeg Dependency: FFmpeg and FFprobe must be available on your system PATH. On Windows, you can simply place ffmpeg.exe and ffprobe.exe in the same directory as UMD2MKV.exe.
  • Platform Support: Native Win32 GUI (UMD2MKV.exe) and CLI for Windows; CLI builds for Linux (amd64/arm64) and macOS (Intel/Apple Silicon). Automated GitHub Actions handle cross-platform compilation on every release.

CLI Quick Reference

# Standard conversion (H.264 stream-copy + AAC-LC 256k + PGS subtitles)
umd2mkv -iso /path/to/movie.iso -out movie.mkv

# Lossless FLAC audio output
umd2mkv -iso /path/to/movie.iso -out movie.mkv -audio flac

# Disable subtitle extraction
umd2mkv -iso /path/to/movie.iso -out movie.mkv -subs=false

# Inspect file structure and CLP metadata without converting
umd2mkv -iso /path/to/movie.iso -inspect

# Perform a deep stream-scan of audio and subtitle tracks
umd2mkv -iso /path/to/movie.iso -scan-tracks

Known Limitations

  • GUI Platform Constraints: The graphical interface is exclusive to Windows; Linux and macOS deployments utilize the command-line interface.
  • Heuristic Stream Selection: Because UMD Video authoring lacks universal flags distinguishing main features from bonus content, Movie mode relies strictly on file size, which may occasionally target longer featurettes.
  • Authoring Variances: CLP mapping and subtitle extraction are designed around standard retail pressings; non-standard or promotional variants may occasionally leave specific track descriptors unlabelled.
